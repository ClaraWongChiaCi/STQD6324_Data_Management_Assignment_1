# STQD6324_Data_Management_Assignment_1
Classification of Iris dataset via Spark MLlib
## Overview
Classification is a widely used technique in Machine Learning for sorting of data into predefined groups called classes. Generally, the algorithm identifies and extracts patterns within the data and subsequently assigns potential classes to new data based on learned trends (Drummond, 2017). The effectiveness of three classification models – Logistic Regression, Random Forest, and Decision Tree, was assessed via the Iris dataset. The dataset was pre-processed and transformed to be used in the PySpark environment, followed by train-test split and hyperparameter tuning through cross-validation. The evaluation metrics results demonstrated that Random Forest outperformed the other two models with feature importance analysis showed petal features to be the main predictors for classification of Iris species. The consistently high accuracies across all models tested suggest that the dataset is well-structured and separable. Overall, the findings illustrated the effectiveness of ensemble approach in achieving high classification accuracy compared to single-model algorithms.
## Methodology
### Data Description
This study utilized the Iris dataset, introduced by Fisher (1936) and accessed via the Scikit-learn library (Pedrogosa et al., 2011). The dataset contains 150 observations comprised from three species of Iris flowers, namely Setosa, Versicolour, and Virginica. Four numerical features of the iris flower were used as predictors to categorize the flower into its classes, which include sepal length, sepal width, petal length and petal width.
### Data Preprocessing
The dataset was first converted from a bunch object into a Spark DataFrame via PySpark version 4.0.2 (Zaharia et al., 2016). The target variable was then casted to a double type to ensure compatibility with machine learning algorithms in Spark MLlib in the later stage. The feature columns were combined to form a single vector through VectorAssembler due to nature of PySpark ML models that accept only single vector input (Gasparini, 2024). The dataset was cached to improve computational efficiency in Spark to accommodate its lazy evaluation mechanism, avoiding the need for repeated computation in iterative processes (Saner, 2024).
### Model Training and Validation
The dataset was split into training and test sets based on 70:30 ratio with a fixed random seed of 42 to allow reproducibility. The training data was fit into three classification models, Logistic Regression, Random Forest and Decision Tree. Each model represents different learning approaches in classification technique whereby Logistic Regression represent the linear method, Random Forest as ensemble method and Decision Tree as tree-based approach for comparison of model performance. Hyperparameter tuning was conducted via Cross Validation using three folds. Parameter grid was defined for each model to determine the optimal hyperparameter based on the highest classification accuracy achieved. 
### Prediction and Evaluation
Predictions were performed on the held-out test set after model training. Comparisons were made between predicted and true labels to evaluate the performance of each model through selected metrics, namely, accuracy, precision, recall and F1-score. Visualization such as confusion matrices was utilized to provide insights into model predictions and to support comparison across models.
## Results and Discussion
### Hyperparameter tuning
Reducing regularization parameter from 1.0 to 0.01 in Logistic Regression, enhances accuracy to 0.9535. However, further reduction to 0.001 leads to a decline in accuracy, suggesting potential overfitting. When regularization is too weak, the model becomes overly sensitive to the training data and may capture noises rather than the general patterns, thus resulting in reduced generalization performance. In contrast, variations in the elastic net parameter have minor impact on model performance, indicate that the selection between L1 and L2 regularization is not critical for this dataset. Whilst for Random Forest, the best performance (0.9287) is achieved with 50 trees, a maximum depth of 5, and Gini impurity. Raising the number of trees beyond the aforementioned value results in marginal to no improvements. This suggests that simple dataset such as Iris does not require a large ensemble for optimal performance. Furthermore, the limited impact of tree depth on model performance explains the effectiveness of ensemble mechanism in mitigating overfitting, thus enabling stable performance even with shallow trees. A similar trend is demonstrated in the Decision Tree model, where increasing the maximum depth beyond five did not improve accuracy. This suggests that the classification boundaries in the Iris dataset are relatively simple and be sufficiently captured by a shallow tree structure. In addition, smaller values of bin parameter improve model performance, implying that excessively fine binning can introduce unnecessary complexity and increase the risk of overfitting. 

Overall, results suggest that the Iris dataset is relatively simple and does not require highly complex models for classification. Both tree-based models achieved optimal performance at relatively shallow depths while Logistic Regression is highly sensitive to regularization strength. 
### Feature Importance
Petal_length and petal_width were consistently identified as the most important features (occupied approximately 90%) in both Random Forest and Decision Tree classification of Iris species, which might suggest that these two features are the primary predictors in the dataset. This is consistent with the findings of Zhou (2022) where better clustering was reported for petal figures compared to sepal figures. While petal width is still considered the most important feature in Logistic Regression, the importance of sepal width comes second to petal width, different to what has identified in tree-based models. This might be due to the fact that linear models assign importance based on coefficients, which directly assess the linear contribution of each feature. Whilst tree-based models calculate feature importance based on reduction in impurity during splitting thus also consider feature interactions in addition to linear effects (Breiman et al., 2017).
### Train Accuracy vs Test Accuracy
The gap between cross-validation and test accuracy is able to provide an insight into model stability whereby smallest gap was demonstrated in Logistic Regression which suggest a consistent and good generalization performance (James et al., 2021). While only a single train-test split was conducted, further validation such as different random splits may be required to validate the robustness across different data splits. In contrast, Random Forest showed largest difference between cross-validation and test accuracy, indicating that the model may be more sensitive towards data variation, despite achieving the highest test accuracy. This aligns with the behaviour of bias-variance trade-off where a more stable performance as well as low variance are usually observed in simpler models like Logistic Regression while complex models such as Random Forest and Decision Tree tend to demonstrate higher variability in exchange for better predictive accuracy (Hastie et al., 2009). The Decision Tree model exhibited a relatively moderate gap compared to the aforementioned model, higlighting its inherent instability as a single-tree model. Decision tree is rather sensitive to small variations in the training data which can lead to a different split structures and consequently different predictions. Despite exhibited Random Forest exhibited the largest accuracy difference, this does not solely indicate model instability but reflects the capacity of the model to capture more complex relationships, thus contributing to a better predictive power (Breiman, 2001; James et al., 2021).
### Evaluation Matrix
Four evaluation metrics were considered in this study, namely accuracy, precision, recall, and F1-score and compared between models to select the best performing model for Iris dataset. The results showed that Random Forest outperformed other models across all performance metrics confirming its superior classification capability, possibly due to its ability to capture nonlinear relationships via ensemble learning.  Similar accuracy was reported by Mondal et al. (2024), achieving approximately 0.97 accuracy. Logistic Regression and Decision Tree demonstrated identical performance across all evaluation metrics, with values slightly lower than Random Forest but still exceeding 90%. This might be attributed to the well-structured and separable nature of the Iris dataset, allowing high accuracy to be achieved even with simple models. Besides, the close values between each evaluation metrics within each model may also indicate balanced classification performance with the absence of significant bias for false positives or false negatives. This is further supported by the confusion matrix results where Setosa class is perfectly classified in both Logistic Regression and Random Forest while misclassifications only occurred between Versicolor and Virginica classes. Notably, Random Forest resulted in fewer misclassification compared to Logistic Regression. 

While all the three models tested demonstrated strong predictive performance, Random Forest proffers the most superior predictive capability whereas Logistic Regression offers more consistent and stable performance as evidenced by the smaller gap between its cross-validated and test accuracies. Overall, this substantiates the fact that ensemble model outperforms single-model approaches in classification predictions, consistent to as reported in multiple literatures (Couronne et al., 2018; Kalyani et al., 2024; Mohammed & Kora, 2023).
